Project Description


The student will create a project named Student Portfolio
consisting of:


An
HTML file (index.html) displaying personal information.
A text
file (about.txt) containing project details.
A
Python file (chart.py) to generate a simple chart.
A
generated chart image (chart.png).
A
README.md file describing the project.



The student will manage all files using Git and upload them
to GitHub.
